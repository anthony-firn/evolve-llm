        Private by design

        Run a language model on your own GPU.

        Choose a model to download it once. It then runs entirely in this tab: a Rust engine compiled to WebAssembly computes every token with WebGPU shaders. Models larger than your GPU's memory run too, reading what does not fit from storage. Your messages never leave this device.

        • No install, no account. A modern browser is all it takes.
        • Stays on your device. No server sees your prompts or replies. Web search is off unless you turn it on.
        • Works offline once a model is saved in the browser.

            GitHub The assistant can work on your GitHub repositories with git and gh, through GitHub's API: clone, change files, commit, push, open pull requests, read CI results and merge. Builds and tests run in your repositories' GitHub Actions. Merging always asks you first.
